# EH — Error History（问题现象流水）

倒序维护。讨论问题时**先读本文件最近条目**，再对照 [`TR.md`](TR.md) 归因。  
规范见 [`../AGENT.md`](../AGENT.md) §0。

---

### EH-20260924-01
- **现象**: 打开总览时缺省 space 卡片没有预览图（无 wallpaper/合成图）。
- **复现**: 呼出 `Ctrl+Alt+Space`，顶部 space 条空白或纯色。
- **环境**: 多显示器；HEIC 壁纸机。
- **影响**: 总览不可用观感。
- **TR**: TR-20260924-01
- **状态**: fixed

### EH-20260924-02
- **现象**: window 预览比例不对，画面显示不全 / 比真实窗口大。
- **复现**: 总览底部 tile 与屏幕上真实窗口尺寸不一致；高 DPI 屏更明显。
- **环境**: ≥150% 缩放显示器。
- **影响**: 拖放目标误判、观感差。
- **TR**: TR-20260924-02
- **状态**: fixed

### EH-20260924-03
- **现象**: 窗口从 space A 拖到 B 后自动切到 B，未保持原 space。
- **复现**: 总览内拖 window preview 到另一 space 卡片。
- **环境**: 任意。
- **影响**: 与「悬停仅 UI 预览」语义冲突。
- **TR**: TR-20260924-03
- **状态**: fixed

### EH-20260924-04
- **现象**: 副屏 space 预览在新窗口进入后不刷新。
- **复现**: 副屏开新窗/移动窗，总览卡片或模型截图滞后。
- **环境**: 双屏。
- **影响**: 副屏预览陈旧。
- **TR**: TR-20260924-04
- **状态**: fixed

### EH-20260924-05
- **现象**: 硬杀 SpaceWM 后窗口仍被隐藏。
- **复现**: 构建时 `Stop-Process -Force`。
- **环境**: 托盘程序无主窗。
- **影响**: 桌面窗口丢失可见性。
- **TR**: TR-20260924-05
- **状态**: fixed

### EH-20260925-01
- **现象**: 使用系统快捷键预设时，Windows 虚拟桌面/任务视图仍被触发。
- **复现**: 设置 System 预设后按 `Win+Tab` 或 `Ctrl+Win+←/→`。
- **环境**: Win10/11。
- **影响**: 双触发，系统 VD 与 SpaceWM 抢焦点。
- **TR**: TR-20260925-01
- **状态**: fixed

### EH-20260925-02
- **现象**: 打开总览后任务栏被完全盖住。
- **复现**: 呼出 overview，底部任务栏不可见/不可点。
- **环境**: 任意。
- **影响**: 无法从任务栏启动程序。
- **TR**: TR-20260925-02
- **状态**: fixed

### EH-20260925-03
- **现象**: 总览打开时点任务栏程序，未落到当前 space/未退出预览。
- **复现**: overview 开启 → 点任务栏图标。
- **环境**: 任意。
- **影响**: 窗口可能仍 cloak 或落在 soft-hover 的 space。
- **TR**: TR-20260925-03
- **状态**: fixed

### EH-20260925-04
- **现象**: 悬停 space 卡片后移开，底部 window 列表仍停在悬停的 space。
- **复现**: 悬停非当前 space 卡片 → 鼠标移出卡片条。
- **环境**: 任意。
- **影响**: 底部条与当前桌面不同步。
- **TR**: TR-20260925-04
- **状态**: fixed

### EH-20260925-05
- **现象**: window 预览在高 DPI 下发糊。
- **复现**: 150%/200% 屏查看底部 tile。
- **环境**: 非 100% 缩放。
- **影响**: 可读性差。
- **TR**: TR-20260925-05
- **状态**: fixed
